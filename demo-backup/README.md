# Demo Backup

`main-flow.png` là ảnh chụp prototype chạy local ở trạng thái sẵn sàng nạp PDF,
dùng để chứng minh frontend và Tutor composer đã khởi động khi live demo gặp lỗi.

## Cách trình bày

1. Mở `main-flow.png`.
2. Chỉ vùng Reader, nút upload và Tutor composer.
3. Nói rõ ảnh không chứa kết quả AI, selected context hoặc artifact.
4. Dùng `eval/results.md` để trình bày output API đã chạy thật.

Backup không thay thế demo live hoặc case lạ do giám khảo chạy tại CP6.
